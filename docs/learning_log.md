# Jarvis — Learning Log

This file records technical understanding gained while building Jarvis.

The entries should primarily be written in the developer's own words.
AI may ask questions, identify gaps or review an explanation, but it should
not replace the learning process with polished summaries that were never
personally understood.

## Entry format

### YYYY-MM-DD — Topic

**What I was trying to build**

Describe the feature or problem.

**How I thought it worked before**

Write the original understanding, including uncertainty.

**What the system actually does**

Explain the important flow in plain language.

**Important code or concept**

Record the central concept without copying an entire implementation.

**What failed**

Describe the observed failure and evidence.

**Why it failed**

Distinguish the confirmed cause from hypotheses.

**How it was verified**

Record the command, test, input or runtime output used.

**What I could now explain without AI**

Summarize what has been internalized.

**What I still do not understand**

Keep unresolved questions explicit.
